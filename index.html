04

AI-Powered HR Applicant Screening System

Form: name, email, resumen8n · GeminiSheets dashboard, score 1–10

An automated recruitment solution that streamlines the initial applicant screening process. Candidates submit their name, email, and resume through a simple form.

A self-hosted n8n workflow (running on Oracle Cloud via Docker) intelligently parses the resume using Google Gemini, extracts key information, and automatically updates a Google Sheets dashboard with a structured summary and an AI-generated suitability score (1–10) based on predefined job requirements.

This system significantly reduces manual HR workload, improves screening consistency, and enables faster, data-driven hiring decisions.

Built with
  • n8n
  • Google Sheets
  • Docker
  • Google Gemini API
